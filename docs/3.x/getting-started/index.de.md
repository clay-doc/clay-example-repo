# Erste Schritte

Installiere Clay, baue in fünf Minuten eine erste Seite und lerne, welche Datei was tut.

Clay macht aus einem Ordner voller Markdown-Dateien eine Dokumentationsseite. Du schreibst Seiten in `docs/`, beschreibst die Seite in der `clay.yaml`, und Clay baut statische Dateien, die du überall veröffentlichen kannst. Keine Templates, kein Theme zum Einrichten, kein JavaScript zum Schreiben.

| Wenn du … willst | Lies |
|------------------|------|
| Clay einem Projekt hinzufügen oder ohne Installation ausprobieren | [Installation](installation.md) |
| Von einem leeren Ordner zu einer fertigen Seite kommen | [Schnellstart](quick-start.md) |
| Wissen, wofür jede Datei und jeder Ordner eines Projekts da ist | [Projektstruktur](project-structure.md) |

## Was du brauchst

- [Node.js](https://nodejs.org) und npm
- Einen Ordner mit Markdown-Dateien, oder die Lust, welche zu schreiben
- Einen Texteditor; `clay dev` zeigt jede Änderung sofort im Browser

> [!TIP]
> Du kennst Clay 2 schon? Spring direkt zum [Umstieg auf Clay 3](../guides/upgrading-to-clay-3.md).
