# Versions & Languages

Keep the docs of older releases online, and translate your docs page by page.

Both work with plain files: older versions are folders in `docs-archive/`, translations are files like `setup.de.md` next to the original. Readers switch between them in the navbar.

| If you want to … | Read |
|------------------|------|
| Keep the docs of an older release online | [Versions](versions.md) |
| Offer your docs in more than one language | [Translations](translations.md) |

## Key ideas

- **`docs/` is always the latest version.** Saving a version copies it into `docs-archive/<name>/`.
- **Translate as much as you like.** Pages without a translation show the original, with a note.
- **Both combine.** Every version can have translations, and the switchers keep the page you are on.
