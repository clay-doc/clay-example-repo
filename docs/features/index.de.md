# Funktionen

Was jede Clay-Seite mitbringt: Suche, Suchmaschinenoptimierung, Seitendetails wie das Inhaltsverzeichnis sowie Designs und Icons.

Nichts davon braucht Einrichtung. Alles funktioniert, sobald du baust; einige Einstellungen in der `clay.yaml` oder im Front Matter verfeinern es.

| Wenn du … willst | Lies |
|------------------|------|
| Wissen, was die Suche findet und wie Leser sie bedienen | [Suche](search.md) |
| Von Suchmaschinen gefunden werden, mit guten Titeln und Vorschauen | [SEO](seo.md) |
| Ein Inhaltsverzeichnis, das Datum der letzten Änderung oder Bearbeiten-Links zeigen | [Seitendetails](page-details.md) |
| Zwischen hell und dunkel wechseln oder eigene Icons nutzen | [Designs & Icons](themes-and-icons.md) |

> [!TIP]
> Drück auf jeder Seite dieser Dokumentation <kbd>Strg</kbd> + <kbd>K</kbd> oder <kbd>⌘</kbd> + <kbd>K</kbd>, um die Suche auszuprobieren.
