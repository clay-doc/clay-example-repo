# Anleitungen

Der Umstieg von früheren Clay-Versionen und Lösungen für häufige Probleme.

| Wenn du … | Lies |
|-----------|------|
| eine Clay-3-Seite betreibst | [Umstieg auf Clay 4](upgrading-to-clay-4.md) |
| eine Clay-2-Seite betreibst | [Umstieg auf Clay 3](upgrading-to-clay-3.md) |
| noch mit Clay 1 und Clay Oven baust | [Umstieg von Clay 1](migrating-from-clay-1.md) |
| auf ein Problem stößt: fehlende Styles, Icons, Bilder oder Daten, oder ein fehlschlagender Build | [Problemlösung](troubleshooting.md) |

> [!NOTE]
> Von Clay 1 auf Clay 3? Folge beiden Anleitungen nacheinander: erst auf Clay 2, dann auf Clay 3.
