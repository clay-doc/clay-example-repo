# Versionen & Sprachen

Halte die Dokumentation älterer Releases online und übersetze deine Dokumentation Seite für Seite.

Beides funktioniert mit einfachen Dateien: Ältere Versionen sind Ordner in `docs-archive/`, Übersetzungen sind Dateien wie `setup.de.md` neben dem Original. Leser wechseln in der Navigationsleiste zwischen ihnen.

| Wenn du … willst | Lies |
|------------------|------|
| Die Dokumentation eines älteren Releases online halten | [Versionen](versions.md) |
| Deine Dokumentation in mehr als einer Sprache anbieten | [Übersetzungen](translations.md) |

## Das Wichtigste

- **`docs/` ist immer die neueste Version.** Beim Speichern einer Version kopiert Clay sie nach `docs-archive/<name>/`.
- **Übersetze so viel du willst.** Seiten ohne Übersetzung zeigen das Original, mit einem Hinweis.
- **Beides lässt sich kombinieren.** Jede Version kann Übersetzungen haben, und die Umschalter behalten die Seite, auf der du bist.
